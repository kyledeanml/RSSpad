# RSSpad Tracks Directory

This folder stores all video and audio episode files, along with their responsive HTML5 preview poster frames.

- **Media Files (`.mp4`, `.mov`, `.m4v`, `.mp3`, `.wav`, etc.)**: Ignored by git blob tracking to stay within GitHub limits; automatically hosted on GitHub Releases (`episodes` tag) with high-speed direct downloads.
- **Poster Frames (`*_poster.jpg`)**: Tracked in git and published directly to GitHub Pages for instant video poster previews.
